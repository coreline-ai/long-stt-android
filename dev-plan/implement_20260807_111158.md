## 개발 목적

현재 사용 중인 whisper.cpp JNI 전사와 STT 설정을 유지하면서, 삼성폰에서 6시간급 전체 포맷 전사를 완주하는 것을 1차 합격 기준으로 삼는다.

- WAV/M4A/MP3 전체 구간을 청크 누락·중복 없이 전사
- 청크 경계의 단어 손실·중복을 방지하고 하나의 통합 텍스트 생성
- 6시간 실행 중 OOM·native crash·앱 종료·발열 쓰로틀 실패 방지
- 화면 종료·백그라운드 전환·프로세스 재시작 이후 중단 지점에서 재개
- 실패 청크 자동 재시도와 실패 범위의 명시적 기록
- 최종 전사 결과가 전체 오디오 coverage를 만족하는지 자동 검증
- 현재 삼성폰/현재 STT 설정의 end-to-end 성능과 결과 보존

## 문서 기반 제약 사항

- 엔진 입력은 16kHz mono float32 PCM이다.
- 기존 지원 포맷은 WAV, M4A, MP3이며 Android MediaCodec을 우선 사용한다.
- 장시간 전사는 기본 10분 청크 단위를 유지한다.
- 1차 검증 기기는 삼성 SM-S931N으로 고정한다.
- 현재 사용 중인 whisper.cpp 엔진·모델·언어 설정을 고정하고 모델 비교는 후속으로 미룬다.
- 6시간급 원본 파일은 포맷별로 실제 파일 전체를 사용해 검증한다.
- 최소 SDK 26과 arm64-v8a 빌드 조건은 유지하되, 타 기기 검증은 6시간 완주 후 진행한다.
- APK의 16KB ELF/ZIP 정렬을 모든 빌드 게이트에서 확인한다.
- 동일 whisper 컨텍스트 재사용은 안정성 검증 전까지 강제하지 않는다.
- 기존 CSV 추출 사용성을 유지하되, 스키마 변경 시 버전을 명시한다.
