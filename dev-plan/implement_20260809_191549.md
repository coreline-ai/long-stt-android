# implement_20260809_191549.md

작성 일시: `2026-08-09 19:15:49 KST`

이 문서는 실제 녹음 1건을 로컬 전사한 뒤, 사용자가 명시적으로 선택·동의한 전사만 Codex OAuth로 요약하는 단일 흐름의 범위를 고정한다.

## 개발 목적

- `녹음 → 로컬 STT → 선택·동의 → 외부 요약 → 결과 확인`을 한 건의 실제 녹음에서 안전하게 완결한다.
- 현재 OAuth 연결·비민감 probe만 있는 상태에서, 전사 원문 자동 전송 없이 사용자 선택형 요약을 제공한다.

## 개발 범위

- 단일 녹음 그룹(모든 child 전사가 완료된 경우)과 단일 완료 전사 결과의 요약 진입점
- 전송 전 동의 dialog, 처리 중 상태, 성공 결과의 앱 내부 저장·재표시
- OAuth 토큰과 원문을 요약 저장소·로그·문서에 복제하지 않는 경계
- 녹음·전사·요약의 동시 실행을 막는 기존 `DeviceWorkCoordinator` lease 사용
- 순수 정책·저장소·UI 계약 테스트 및 기존 전체 회귀 게이트

## 제외 범위

- 자동 요약, 백그라운드 대량 요약, 6시간 원본 분할·재개 요약, export/sync
- OAuth protocol, endpoint, client ID, model allowlist 변경 또는 새 외부 의존성
- 사용자 동의 없는 전사 전송, 원문·token·계정 정보 출력
- 사용자 데이터·모델·녹음 삭제 및 `adb uninstall`/`pm clear`
