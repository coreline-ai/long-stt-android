# implement_20260808_085631.md

작성 일시: `2026-08-08 08:56:31 KST`

이 문서는 Phase 5의 범위를 고정하고, 녹음 원본을 기존 단일 파일 전사 경로에 안전하게 연결하는 작업을 추적한다.

## 개발 목적

직접 녹음으로 확정된 READY 청크를 통합 MediaLibrary에 중복 없이 등록하고, 녹음 세션 단위의 순차 전사와 그룹 결과 보관함을 구현한다.

## 개발 범위

- READY 녹음 청크의 MediaLibrary 자동 등록과 sequence 무결성 검증
- 녹음 전사 부모 그룹·자식 STT checkpoint의 원자 저장
- 기존 `TranscriptionService`만 사용하는 순차 child 전사 coordinator
- 녹음 session/group/media 연결 메타데이터와 process 재진입 복원
- 완전 세션과 일부 보존 세션의 명확한 구분·확인 흐름
- 녹음 화면 전사 시작 CTA와 통합 보관함 그룹 상세
- 원본 숨기기·원본 파일 삭제·전사 결과 삭제의 분리
- 녹음과 STT의 장시간 작업 상호 배제

## 제외 범위

- 여러 native whisper engine의 병렬 실행
- 1시간·6시간 장시간 완주 및 release gate(Phase 7)
- 기존 전사 화면의 대규모 파일 분해·route 재구성(Phase 6)
- quarantine 파일의 자동 복원 또는 강제 전사
- 녹음 청크 병합·재인코딩
