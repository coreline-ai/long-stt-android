# implement_20260813_160122.md

작성 일시: `2026-08-13 16:01:22 KST`

이 문서는 전사 채팅의 검증된 근거를 확인한 뒤 기존 대화로 즉시 복귀하는 GUI 개선 범위를 고정한다.

## 개발 목적

- 검증된 근거 클릭이 대화 route를 제거하고 보관함으로 이동하는 문제를 수정한다.
- 일반 `전체 전사`와 채팅의 `근거 확인` 진입 목적을 제목·강조·복귀 action으로 구분한다.
- 근거 확인 전후에 대화 메시지, 질문 초안, 모드와 스크롤 맥락을 보존한다.

## 개발 범위

- 전체 전사 viewer를 `ui/common`의 공용 UI로 분리한다.
- viewer에 일반 전체 보기와 채팅 근거 확인 모드를 추가한다.
- 채팅 route 안에서 선택 근거를 saveable overlay 상태로 관리한다.
- 근거 section 강조, 상·하단 `대화로 돌아가기`, Android back dismiss를 제공한다.
- 접근성 문구를 `전체 전사에서 보기`가 아닌 `근거 확인`으로 교체한다.
- Compose 회귀 테스트, 앱 unit test, lint, Debug build와 diff 검증을 수행한다.

## 제외 범위

- navigation graph 전체 재작성과 보관함 상세 구조 변경
- citation 생성·검증, LLM 요청, 인덱스·대화 저장 계약 변경
- 전체 전사 TXT 저장·파일 공유 GUI 변경
- 실제 OAuth 로그인, 실제 외부 LLM 요청, 실제 사용자 전사 출력
- 앱 데이터 삭제, `.commandcode/` 수정·스테이징

## 엔지니어링 검토

1. **Verdict: ready**
2. **최상위 위험:** 기존 `popUpTo`가 채팅 route를 제거해 복귀 맥락을 잃고, 일반 전체 보기와 근거 확인이 동일한 제목·닫기 action을 사용한다.
3. **아키텍처 계약:** 공용 viewer는 렌더링만 소유하고, 채팅 화면은 선택 근거의 불투명 ID·시간·section key만 saveable 상태로 소유한다.
4. **상태 계약:** overlay dismiss는 선택 근거만 비우며 ViewModel, 대화 route와 LazyColumn을 제거하지 않는다.
5. **실패 계약:** source/section이 없으면 viewer를 열지 않거나 안전하게 빈 강조 상태로 표시하고 navigation을 바꾸지 않는다.
6. **회귀 계약:** 보관함의 일반 전체 전사에는 기존 TXT 저장·파일 공유와 `닫기`를 유지한다.
7. **테스트 계약:** 근거 열기·상하단 복귀·접근성 문구·상태 복원·200% 글자와 일반 viewer 회귀를 자동화한다.
