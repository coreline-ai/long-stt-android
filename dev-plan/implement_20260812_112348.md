# implement_20260812_112348.md

작성 일시: `2026-08-12 11:23:48 KST`

이 문서는 저장된 요약의 상태를 보관함 목록에서 즉시 확인하고, 사용자가 선택한 완료 요약만 Android 시스템 공유 시트로 전달하는 후속 개발 범위를 고정한다.

## 개발 목적

- 보관함 상세를 열지 않아도 단일 전사와 녹음 그룹의 요약 가능·진행·완료·오류 상태를 구별한다.
- 완료 요약을 사용자의 명시적 공유 동작으로 Google Chat을 포함한 설치 앱에 전달한다.
- 전사 원문, source ID, 파일 경로, OAuth·계정 정보가 공유 payload에 섞이지 않는 계약을 유지한다.

## 개발 범위

- 단일 전사 결과와 녹음 그룹 목록 카드의 요약 상태 표시
- `요약 가능`, `요약 중 · 정수%`, `요약 완료`, `요약 확인 필요` 상태와 완료 요약 1~2줄 미리보기
- 완료 요약 상세 카드의 `요약 공유` 액션
- Android `ACTION_SEND`, `text/plain`, 시스템 Sharesheet를 통한 설치 앱 선택
- 공유 앱을 열 수 없는 예외의 비민감 사용자 안내
- 상태 판정·공유 payload·Compose UI·기존 요약 회귀 테스트

## 제외 범위

- 전사 원문, 오디오, 내부 JSON, 파일 경로, source ID의 공유
- Google Chat 등 특정 앱 패키지 강제 지정 또는 자동 발송
- 첨부 파일, PDF·문서 export, 클라우드 sync, 공유 이력 저장
- `SummarySessionStore` schema 변경이나 완료 요약 재생성
- 사용자 데이터 삭제, `adb uninstall`, `pm clear`, Git commit·push

## 문서 기반 제약 사항

- 목록의 완료 정본은 `SummarySessionStore.Entry`, 실행 정본은 `SummaryUiState`로 유지한다.
- Android 표준 Sharesheet를 사용하며 신규 외부 의존성을 추가하지 않는다.
- 공유 payload에는 저장된 최종 요약문과 일반 제목만 포함한다.
- 공유는 완료 요약 카드에서 사용자가 버튼을 누른 경우에만 시작한다.
- 목록 카드의 기존 전체 클릭 동작과 최소 터치 영역을 유지한다.

## 최종 결과 요약

- 보관함 단일 전사·녹음 그룹 카드에 source별 요약 상태를 표시한다.
- 저장 완료 상태는 `요약 완료` pill과 최대 2줄 미리보기를 노출하며 Samsung 실제 저장 요약 목록에서 표시를 확인했다.
- 완료 상세 첫 화면에 `요약 공유` 버튼을 배치했다.
- 공유는 `ACTION_CHOOSER` 안의 `ACTION_SEND`, `text/plain`으로 구성하며 일반 제목과 저장 최종 요약문만 포함한다.
- 전체 앱 테스트 `134`개가 failure/error/skip 0으로 통과했고 `lintDebug`, `assembleDebug`, `git diff --check`가 통과했다.
- Debug APK SHA-256은 `3782b92d632c27883b765b84d2d52cc47e3dfadc27ed9badb05ce6fad918fd9f`다.
- Samsung SM-S931N에 `install -r`로 설치했고 완료 전사·저장 요약 파일의 보존과 앱 cold start를 확인했다.
