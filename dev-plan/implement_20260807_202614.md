## 개발 목적

현재 LongSTT Android의 장시간 전사·체크포인트·미디어 보관함을 훼손하지 않으면서,
참조 앱의 Quiet Archive GUI와 안전한 마이크 녹음 흐름을 선별 적용한다. 사용자는 첫 실행에서
제품을 이해하고, 첫 화면에서 녹음을 시작하며, 완료된 녹음 세션을 신규 그룹 전사
coordinator를 통해 기존 단일 파일 STT와 통합 보관함으로 연결할 수 있어야 한다.

## 공통 진행 규칙

- 선행 계획의 P0 STT 상태·저장 안정성 gate를 우회하지 않는다.
- 현재 작업 트리의 미커밋 변경과 기존 6시간 체크포인트를 삭제·재저장하지 않는다.
- 녹음 기능은 실제 foreground service, finalize, recovery가 검증되기 전 제품 UI에서 활성화하지 않는다.
- 화면 상태는 service/checkpoint의 구조화 상태에서 만들고 파일 존재 여부로 추측하지 않는다.
- `.part`, quarantine, 0바이트 파일은 오디오 보관함에 등록하지 않는다.
- 녹음/STT/요약은 `DeviceWorkCoordinator`를 통해 한 시점에 하나만 실행한다.
- 각 Phase는 구현, 자동 테스트, 이슈 해소, 완료 조건을 모두 통과한 뒤 다음으로 이동한다.
- 참조 코드·에셋은 원본 commit과 provenance를 기록하고 재사용 승인을 확인한 뒤 반영한다.
- Samsung 명령은 고정 serial을 명시하고 설치·데이터 변경 전 백업 상태를 재확인한다.
- transcript, 녹음 내용, OAuth token/account 식별자는 로그·fixture·스크린샷에 남기지 않는다.
- 큰 UI 변경, recorder core, media migration, STT 연결을 한 commit에 섞지 않는다.
