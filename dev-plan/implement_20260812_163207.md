# implement_20260812_163207.md

작성 일시: `2026-08-12 16:32:07 KST`

이 문서는 전사 완료 직후 사용자가 한 번의 클릭으로 보관함의 정확한 완료 결과 상세를 열 수 있게 하는 개발 범위를 고정한다.

## 개발 목적

- 전사가 완료되면 전사 화면에 `보관함에서 결과 보기` CTA를 지속적으로 노출한다.
- CTA는 보관함 첫 화면이 아니라 방금 완료된 단일 전사 또는 녹음 그룹 상세를 정확히 연다.
- 장시간 백그라운드 완료 중 사용자의 현재 화면을 강제로 바꾸지 않고 명시적 클릭으로만 이동한다.

## 개발 범위

- 완료 단일 전사와 완료/부분 완료 녹음 그룹을 구분하는 불투명 결과 대상 계약
- 완료 이벤트에서 결과 대상을 `SttViewModel.UiState`에 고정
- 전사 완료 카드의 `보관함에서 결과 보기` CTA와 접근성 설명
- 상위 내비게이션의 일회성 보관함 상세 열기 요청
- 보관함 route의 정확한 단일/그룹 상세 선택과 누락 시 목록 폴백
- 단위·Compose·전체 회귀·Samsung 실기기 전환 검증

## 제외 범위

- 전사 완료 시 자동 화면 이동
- 완료 알림의 딥링크 또는 Snackbar 액션
- 요약 자동 시작, 외부 전송, 공유 자동 실행
- 보관함·전사 저장 schema 변경 또는 신규 영구 저장소

## 문서 기반 제약 사항

- 결과 source of truth는 `TranscriptionSessionStore.Checkpoint`와 `RecordingTranscriptionGroupStore.Group`이다.
- `updatedAtMs`나 목록 첫 항목으로 최근 결과를 추정하지 않고, 완료 서비스 이벤트의 정확한 session/group ID만 사용한다.
- UI·SavedState에는 불투명 type/ID만 전달하고 전사 원문·경로·note를 복제하지 않는다.
- 녹음 그룹의 `PARTIAL_COMPLETED`는 보관함 상세 열기 대상이지만 전체 요약/export 가능 여부는 기존 정책을 유지한다.
- 새 전사가 시작되면 이전 완료 CTA target은 지워 중복·오인 이동을 막는다.
- 사용자가 완료 뒤 새 오디오를 선택·가져오거나 입력을 비우면 `DONE`을 준비 상태로 전환하고 이전 target을 제거한다.
