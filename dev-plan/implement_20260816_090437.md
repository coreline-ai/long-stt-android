## 개발 목적

- 전사 기반 AI 대화와 근거 확인 화면을 Quiet Archive 디자인 체계에 맞춰 재구성한다.
- 대화 route에서도 기존 `녹음 / 전사 / 보관함 / 설정` 하단 내비게이션을 유지하고 `보관함` 선택 상태를 표시한다.
- 기존 보관함과 하단 바의 실제 색상·선택 indicator·시스템 내비게이션 배경을 일치시킨다.
- 근거 확인 화면의 시스템 바와 복귀 CTA가 Samsung 3버튼 내비게이션에서 가려지지 않도록 한다.
