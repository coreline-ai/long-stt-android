# implement_20260813_085750.md

작성 일시: `2026-08-13 08:57:50 KST`

이 문서는 P1 실기기 안정성 검증 범위를 자동화 가능한 계약과 사용자·외부 장비가 필요한 수동 게이트로 분리하고, 기존 사용자 데이터를 보존한 상태에서 실제 결과만 기록하기 위한 작업 문서다.

## 개발 목적

- 그룹 전사 완료 target·알림·딥링크가 standalone 완료 경로와 동일한 실패 폐쇄형 계약을 따르는지 검증한다.
- 요약 공유, 전체 전사 TXT 저장·파일 공유가 chooser 부재·보안 예외·쓰기 실패에서도 앱을 종료시키지 않도록 자동 회귀를 보강한다.
- 장시간 imported single-file이 전체 파일을 메모리에 올리지 않는 코드 경계와 OAuth lifecycle의 저장·갱신·401·로그아웃 계약을 자동 테스트로 확인한다.
- Samsung SM-S931N에서 기본 앱 데이터를 지우지 않고 설치·알림·백그라운드 자원 상태를 비민감 metadata만으로 점검한다.

## 개발 범위

- 완료 그룹의 마지막 child terminal event → 그룹 정본 → type/ID target → 완료 알림 계약
- 완료 알림의 explicit·immutable PendingIntent, 고정 알림 ID, 알림 권한 거부 경계
- 요약 공유와 TXT 저장·파일 공유의 Activity 미존재·SecurityException·provider/쓰기 실패 처리
- 오디오 URI의 스트리밍 `.part → final` 복사, 실패 파일 정리, URI·내부 경로 비노출
- OAuth token 저장·복원·single-flight refresh·401 refresh·실패 시 credential 삭제·logout 자동 검증
- Debug/Release/deviceTest 빌드, lint, release surface, 16KB, diff 검사
- Samsung SM-S931N 데이터 보존 Debug 설치와 격리된 deviceTest smoke
- README, 최신 handoff, 본 계획의 실제 결과 갱신

## 문서 기반 제약 사항

- 완료 결과 정본은 `TranscriptionSessionStore`와 `RecordingTranscriptionGroupStore`이며 저장·Intent에는 안전한 type/ID만 허용한다.
- 중간 group child 완료는 target이나 완료 알림을 만들지 않고 마지막 terminal group만 만든다.
- 공유 Intent는 `content://`, `text/plain`, 임시 읽기 권한만 사용하며 전체 전사는 `EXTRA_TEXT`로 전달하지 않는다.
- 장시간 가져오기는 입력 stream을 파일로 순차 복사하고 완료 전 `.part`를 final로 바꾸지 않는다.
- 실제 계정 lifecycle과 실제 6시간 원본 결과는 자동 fixture로 대체해 통과 처리하지 않는다.
- `.commandcode/`와 기존 미커밋 변경은 사용자 소유로 간주하고 수정·스테이징하지 않는다.
