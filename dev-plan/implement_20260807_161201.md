# implement_20260807_161201.md

작성 일시: `2026-08-07 16:12:01 KST`

이 문서는 전사 결과의 다중 형식 내보내기와 외부 문서 가져오기 개발 범위를 고정하고, 구현이 기존 6시간 STT 안정성을 해치거나 문서 편집·클라우드 기능으로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적

완료된 장시간 전사 결과를 `TXT`, `Markdown`, `PDF`로 안전하게 저장·공유하고, 외부의 `TXT`, `Markdown`, 텍스트 기반 `PDF`를 앱에 가져와 전사 결과와 함께 문서 보관함에서 조회·삭제할 수 있게 한다.

전사 session JSON은 계속 전사 결과의 원본이며 CSV는 성능 기록으로 유지한다. 내보내기 파일은 원본을 변환한 산출물이고, 가져온 문서는 원본 파일과 요약·검색용 정규화 텍스트를 분리해 보존한다. 향후 외부 LLM 요약은 공통 문서 읽기 계약을 재사용한다.

## 개발 범위

- 완료 전사와 가져온 문서를 공통 `DocumentSnapshot`으로 읽기
- TXT·Markdown·PDF 내보내기와 타임스탬프 옵션
- Storage Access Framework를 통한 저장 위치 선택
- `FileProvider`를 통한 외부 앱 공유
- TXT·Markdown·텍스트 PDF 다중 가져오기
- 외부 앱의 문서 공유 수신
- 원본 내부 복사, SHA-256 중복 판정, 정규화 텍스트 생성
- 전사 문서와 가져온 문서를 구분하는 통합 문서 보관함
- 진행·취소·실패·재시도·삭제 GUI
- 166,870자 한국어 전사와 삼성 SM-S931N 실기기 검증

## 책임 경계

- `TranscriptionSessionStore`: 기존 전사 checkpoint와 세그먼트의 유일한 원본
- `ImportedDocumentStore`: 가져온 원본·정규화 텍스트·metadata의 원자 저장과 삭제
- `DocumentRepository`: 두 source 목록 통합과 형식 중립 `DocumentSnapshot` 생성
- `DocumentImporter`: MIME·확장자·크기·인코딩 검증, 복사, hash, 텍스트 추출
- `DocumentExporter`: snapshot을 TXT·Markdown·PDF로 변환
- `DocumentExportCoordinator`: 진행·취소·임시 파일 검증·SAF 복사·공유 cache 정리
- `DocumentViewModel`: 문서 화면 상태를 담당하고 기존 `SttViewModel`에 파싱 책임을 추가하지 않음

가져온 문서는 `files/documents/<documentId>/` 아래에 `original.<ext>`, `content.txt`, `metadata.json`으로 저장한다. 전사 문서는 본문을 복제하지 않고 `sourceSessionId`로 checkpoint를 참조하며, 중복 판정은 파일명이 아닌 원본 byte SHA-256을 사용한다.

## Phase 4. 외부 TXT·Markdown 가져오기

- [ ] `OpenMultipleDocuments`로 허용 MIME·확장자만 받는다.
- [ ] 외부 filename을 경로로 사용하지 않고 UUID 임시 파일로 복사하며 SHA-256을 계산한다.

- [ ] Markdown 원본과 읽기 순서를 보존한 정규화 텍스트를 분리 저장한다.
- [ ] 같은 hash는 중복 복사하지 않고 기존 문서 열기를 안내한다.
- [ ] 성공 후에만 metadata/index를 원자 저장하고 실패·취소 파일을 정리한다.
