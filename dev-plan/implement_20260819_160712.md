## 개발 목적

Long STT의 완료 전사 TXT와 완료 요약 TXT를 사용자가 승인한 자신의 Google Drive에 직접 저장한다. 앱 자체 회원가입·프로필·서버 저장소는 만들지 않으며, 수동 업로드와 명시적 opt-in 자동 업로드만 제공한다.

## 범위와 제외 범위

- Google Identity Services `AuthorizationClient`와 Google Drive `drive.file` 하나만 사용한다.
- 설정의 연결·재연결·연결 해제, 전사 상세의 수동 선택 업로드, 완료 이후 자동 업로드, 보관함 상태 표시를 제공한다.
- 전사와 요약은 기존 저장소를 원본으로 유지하고 업로드 직전에 앱 cache의 UTF-8 `text/plain` 파일로 생성한다.
- Drive 앱은 기존 Android Sharesheet의 선택 대상이 되는 폴백으로 유지한다. 별도 Drive 앱 package 하드코딩이나 Drive 전용 forwarding action은 만들지 않는다.

제외:

- 앱 회원가입, 백엔드·Firebase·Google Cloud Storage 버킷, 서비스 계정, 서버 중계
- Drive 전체 파일 권한, 기존 파일의 광범위한 검색·동기화·삭제, 양방향 동기화와 공동 편집
- access token·계정 식별자·전사 원문·요약문·원본 경로를 로그·WorkManager `Data`·일반 preferences에 저장
- 초기 버전의 resumable session URI 영구 저장과 바이트 단위 resume

## 원격 계획 보완 반영 및 결정 기록

- 완료 단일 전사와 전체 완료·비부분 녹음 그룹만 업로드 source로 허용한다. 진행 중·부분 완료·삭제·손상 source는 fail closed 한다.
- 최종 `SummarySessionStore` 결과만 `summary.txt`로 만들며, 요약 없음은 transcript 업로드를 막지 않는다.
- 자동 업로드는 기본 `OFF`이고 사용자가 켠 시각 이후 완료되는 결과에만 적용한다. 기존 보관함은 자동 백필하지 않는다.
- `Long STT` root와 결과 폴더는 앱 소유 `appProperties`, `trashed=false`, parent 조건으로 찾거나 생성한다. 원격 중복 판별에는 원문·제목·source ID 대신 불투명 `exportId`와 artifact kind만 사용한다.
- WorkManager 입력은 불투명 `jobId` 하나다. source type/ID, Drive folder/file ID, 전사·요약문, token, session URI를 넣지 않는다.
- access token은 요청 메모리 범위에서만 사용한다. 계정 이메일·프로필·raw identifier·refresh token을 앱이 저장하거나 표시하지 않는다.
- Worker는 사용자 승인 UI를 열지 않는다. 승인이나 재승인이 필요하면 `AUTH_REQUIRED`만 기록하고 설정의 사용자 조작으로 되돌린다.
- cache 정리는 `cache/drive_exports/<opaque-job-id>` 범위로 제한한다. Drive HTTP 직접 업로드에는 FileProvider URI가 필요 없으며, 기존 전체 전사 Sharesheet 계약은 그대로 유지한다.
- 재개 URI를 저장하지 않는 현재 설계에서는 프로세스 종료 뒤 파일을 처음부터 새 resumable session으로 업로드하고, 앱 생성 파일 조회로 중복을 막는다.

## 보안·데이터 계약

- Google scope는 `https://www.googleapis.com/auth/drive.file` 단 하나다.
- Drive 작업 상태에는 job/export/source 참조, artifact, 상태·byte 수·retry 수·Drive folder/file ID만 둔다. 원문·요약문·오디오/모델 경로·token·계정 정보는 제외한다.
- Drive 파일 metadata에는 `longSttRoot`, `longSttExportId`, `longSttArtifact`만 사용한다. 원본 파일명·메모·source ID를 넣지 않는다.
- HTTP 오류와 UI 문구에는 response body·token·원문·경로를 포함하지 않는다.
- 연결 해제는 먼저 대기·실행 Work를 취소하고 연결 세대를 무효화한 뒤, 가능한 경우에만 임시 Account로 Google 권한을 철회한다. 이미 저장된 Drive 파일은 삭제하지 않는다.
