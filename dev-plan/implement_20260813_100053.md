# implement_20260813_100053.md

작성 일시: `2026-08-13 10:00:53 KST`

이 문서는 완료 전사 전체를 근거로 현재 앱에 연결된 Codex LLM과 대화하는 P2 구현 범위를 고정한다.

## 개발 목적

- 완료된 단일 전사와 전체 완료 녹음 그룹에서 `전사와 대화`를 시작한다.
- 첫 외부 처리 전에 동의를 받고, 원문을 저장소에 복제하지 않는 로컬 인덱스와 대화 기록을 제공한다.
- 빠른 질문은 관련 구간만, 사용자가 직접 고른 전체 정밀 탐색은 모든 구간을 순차 처리한다.
- 답변 근거를 검증된 시간 chip으로 표시하고 기존 전체 전사 보기의 해당 구간으로 이동한다.
- 기존 전체 보기·TXT 저장/공유·외부 요약·완료 CTA와 OAuth 보안 계약을 회귀시키지 않는다.

## 개발 범위

- AtomicFile 기반 원문 없는 인덱스·대화·정밀 탐색 checkpoint

- 스트리밍 채팅 ViewModel과 동의·인덱싱·검색·답변·오류 GUI
- 전체 정밀 탐색, citation allowlist, 전체 전사 section 이동
- 자동 단위·Compose·회귀·품질 게이트와 비민감 Samsung smoke

## 엔지니어링 검토

- **Verdict:** 필요한 계약을 아래와 같이 고정하면 구현 가능.
- source 정본은 `TranscriptSourceDocument`; index/session/checkpoint는 파생 요약·불투명 ID만 저장한다.
- 화면 재생성은 저장된 완료 결과만 복원하고 진행 중 POST를 자동 재실행하지 않는다.
- provider citation은 현재 요청의 unit allowlist와 대조한 뒤에만 시간 chip이 된다.
- `CodexLlmRequestCoordinator`와 `DeviceWorkCoordinator`에 CHAT owner를 추가해 요약·녹음·전사와 충돌을 차단한다.
- controller는 delta callback을 제공하되 OAuth 401 1회 refresh 계약은 기존 `OAuthLlmSession`에 위임한다.
- 429/5xx/timeout/손상 stream은 비민감 오류로 종료하고 사용자가 재시도해야 한다.
- 단위 테스트는 저장 JSON 금지 필드, 요청 body, 취소/재개, 검색 결정성, citation, 진행률을 우선한다.

## 최종 잔여 위험

- 실제 OAuth 계정 로그인·401 refresh·로그아웃 lifecycle은 이번 실행에서 수행하지 않았고 기존 OAuth 43건 자동 테스트로만 검증했다.
- 실제 외부 LLM 요청과 실제 전사 인덱싱·빠른 질문·정밀 탐색의 응답 품질/비용/지연은 사용자 승인된 비민감 데이터로 후속 확인이 필요하다.
- 합성 근거 chip 콜백은 실기기에서 확인했지만 실제 standalone/group 전체 전사 section 착지는 사용자 전사를 열지 않는 원칙 때문에 자동 테스트로만 검증했다.
- 실제 릴리스 시 Coreline이 사용하는 인증 구성·모델 이용 정책·한국어 전사 Q&A 품질을 확인한다. Codex 관련 별도 공식 승인 gate는 아니다.
