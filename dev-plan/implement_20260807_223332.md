## 공통 진행 규칙

- service runtime/checkpoint를 UI의 source of truth로 사용한다.
- UI 자체 timer나 파일 존재 추측으로 녹음 상태를 만들지 않는다.
- 권한이 없으면 foreground service를 먼저 시작하지 않는다.
- 테스트 녹음과 화면 캡처는 `com.stt.benchmark.deviceTest`에서 수행한다.
- 기존 `com.stt.benchmark` 앱 데이터는 `install -r`로 보존한다.
- README 이미지는 `docs/screenshots/` 상대 경로를 사용하고 민감정보를 포함하지 않는다.
- 새 외부 앱 의존성을 추가하지 않는다.
