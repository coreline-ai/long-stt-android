## 개발 목적

공개 배포 전 필수 보안 구현 4개를 소스와 배포 자동화에 반영한다.

1. Android API 36 target/compile 전환
2. Whisper 모델 다운로드의 고정 revision·크기·SHA-256 검증
3. OAuth loopback callback의 state-first 검증
4. 저장소 밖 signing secret을 사용하는 signed AAB 배포 파이프라인

## 개발 범위

- `app`과 `codex-oauth-android`의 SDK target을 API 36으로 통일한다.
- 공식 Hugging Face revision에 고정된 모델 목록과 스트리밍 무결성 검증을 구현한다.
- localhost socket callback은 state가 일치할 때만 authorization 결과를 완료하게 한다.
- Gradle production signing contract, signed AAB 검증/provenance task, GitHub Actions 수동 release workflow 및 운영 문서를 추가한다.
- 각 변경에 대응하는 단위 테스트와 release 빌드/lint를 실행한다.

## 제외 범위

- 실제 upload keystore 생성·비밀값 저장·Play Console 업로드
- OAuth redirect URI 자체의 서비스 제공자 등록 변경
- 민감 데이터 암호화, 보관 기간/실제 삭제, SAF import 용량 제한 등 후속 보안 항목
- 라이브러리 전체 버전 업그레이드 및 기능/UI 리팩터링
