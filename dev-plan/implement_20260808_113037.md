- [x] 20× START/STOP 실기기 gate가 `ForegroundServiceDidNotStartInTimeException`을 재현했다. terminal STOP이 새 START를 무조건 종료하지 않도록 `startId`를 command/terminal에 전달하고 `stopSelfResult(startId)`로 수정했다. 수정 뒤 단일 20회 test 및 전체 12 deviceTest가 통과했다.
- [x] 200% font scale에서 4개 bottom navigation label이 겹쳤다. 130%까지 label을 유지하고 그 이상에서는 TalkBack icon description은 보존한 채 visible label을 compact 처리했다. Samsung 200%/360×800 캡처에서 겹침이 사라졌다.
- [x] 실제 제품 recorder foreground notification이 drawer에 표시되지 않아 stop action을 누를 수 없었다. 원인은 Android 13+ `POST_NOTIFICATIONS` runtime permission을 제품 route가 요청하지 않은 것이었다. 녹음 시작 시 권한이 없으면 먼저 한 번 요청하고 결과 뒤 recording을 시작하도록 구현했다. permission policy unit test 3개와 Samsung allow → notification expand → `녹음 정지` → app re-entry를 통과했다.
- [x] `verify16KbAlignment`가 broad `merged_native_libs` input으로 deviceTest merge output의 암묵 의존성 오류를 냈다. Debug/Release input만 선언하도록 좁혀 full static gate가 통과했다. nav 수정 뒤에는 최종 re-gate가 다시 필요하다.
- [x] 롤오버 첫 시도는 `am force-stop` 직후 비동기 종료가 새 프로세스를 종료한 test-harness sequencing 문제로 중단됐다. startup recovery는 unfinalized part를 quarantine으로 보존하고 FAILED checkpoint로 전환했다. 5초 대기 뒤 실제 20분 재시도를 시작했으며, 결과 전에는 rollover 성공으로 표시하지 않는다.
- [x] 재시도에서 20분 default chunk rollover가 실제 발생했다. 첫 M4A 1,199,981ms/56,250 packets, 둘째 M4A 147,048ms/6,893 packets이며 두 container PTS는 독립적으로 0에서 시작한다. chunk duration 합과 session elapsed 차이 296ms가 1초 기준 안에 있어 gap/overlap은 관측되지 않았다. terminal 뒤 비격리 `.part` 0, 0-byte 0, RecorderService/WakeLock 0이다.
- [x] 22:27·2청크 session의 최초 background group 실행은 child 0 완료 뒤 child 1 foreground-service 시작이 거부되어 안전하게 FAILED로 terminal 저장됐다. Android 16 background start 제한을 회피하려고 terminal checkpoint 저장 뒤 service 내부에서 다음 child launch를 준비하고, 이전 service의 cleanup 뒤 직접 launch하도록 수정했다. 재시도는 홈 이동 상태에서 child `0=COMPLETED`, `1=COMPLETED`, group `COMPLETED` 및 STT service/wake lock 없음으로 종료됐다. Debug-only in-app metadata audit은 원문·경로·ID를 노출하지 않고 `AUDIT_PASS_CHILDREN=2_COVERAGE=COMPLETE`를 표시했다.
