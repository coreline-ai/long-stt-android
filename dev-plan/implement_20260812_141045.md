# implement_20260812_141045.md

작성 일시: `2026-08-12 14:10:45 KST`

이 문서는 기존 전체 전사 보기·외부 요약·요약 상태·요약 공유 기능을 기준선으로 삼아, 전체 전사 파일 저장/공유와 현재 ChatGPT OAuth 연결 기반 전사 채팅을 하나의 후속 개발 흐름으로 통합한다.

## 개발 목적

- 사용자가 완료된 전사 원문 전체를 앱에서 확인하고 UTF-8 TXT로 안전하게 저장하거나 파일로 공유할 수 있게 한다.
- 사용자가 명시적으로 선택·동의한 전사를 현재 연결된 ChatGPT/Codex Responses 경로로 질문하고, 답변 근거가 되는 전사 시간 범위를 확인할 수 있게 한다.
- 긴 전사를 매 질문마다 통째로 전송하지 않고, 로컬 구간 인덱스와 필요한 원문만 사용해 컨텍스트 한도·응답 지연·외부 전송량을 제한한다.
- 누락이 허용되지 않는 질문에는 전체 전사 정밀 탐색을 별도 모드로 제공하고 단계별 진행 상황을 표시한다.
- 전사 원문, OAuth 정보, 내부 경로가 저장소·로그·공유 payload에 불필요하게 복제되지 않는 기존 보안 경계를 유지한다.

## 문서 기반 제약 사항

- 외부 전송은 완료된 전사를 사용자가 선택하고 동의한 경우에만 허용한다.
- 전사 원문은 OAuth 저장소, 채팅 인덱스, 일반 로그, crash report, 문서, 스크린샷에 복제하지 않는다.
- 채팅 저장소에는 사용자 질문, 사용자에게 표시된 답변, 검증된 근거 ID/시간, 상태와 timestamp만 저장한다.
- 인덱스와 정밀 탐색 checkpoint에는 생성된 짧은 구간 요약·발견 결과만 저장하고 원문 구간은 저장하지 않는다.
- inference POST는 명시적 idempotency 계약이 없으므로 자동 재시도하지 않는다. 실패 후 재시도·재개는 사용자 동작으로만 수행한다.
- 현재 adapter의 `store=false`, 고정 endpoint/header, model allowlist를 유지한다.
- 요약과 채팅은 앱 수준 LLM 요청 직렬화 경계를 공유해 동시에 OAuth 요청을 실행하지 않는다.
- 현재 작업 트리의 기존 미커밋 변경은 사용자 소유로 간주하고 보존한다.
- 앱 내부 checkpoint를 전부 문자열로 합치지 않고 정렬된 청크·세그먼트를 순차 처리한다.

## 잔여 리스크 / 후속 과제

- 현재 `gpt-5.3-codex-spark`는 Codex 용도 모델이며 전사 Q&A 품질은 합성 fixture와 실제 비민감 한국어 전사로 별도 평가해야 한다.
- 로컬 문자 기반 검색은 표현이 크게 다른 의미 질문을 놓칠 수 있다. 이번 범위에서는 전체 정밀 탐색을 누락 보완 경로로 사용한다.
- hosted file search와 server compaction은 자체 백엔드·API credential·보존 정책이 확정된 별도 workstream에서만 재검토한다.
- 실제 릴리스 시에는 Coreline이 사용하는 인증 구성과 제3자 구성요소의 고지·라이선스, 적용 서비스 약관을 확인한다. Codex 관련 별도 공식 승인 gate는 아니다.
- 실제 요약 공유, TXT 파일 공유, 외부 앱 발송과 실제 계정 채팅은 사용자 명시 동작 경계를 유지한다.
