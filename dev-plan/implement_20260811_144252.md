# implement_20260811_144252.md

작성 일시: `2026-08-11 14:42:52 KST`

이 문서는 앱의 핵심 제품 이미지를 교체하는 범위를 고정하고, 생성형 이미지 적용이 기존 녹음·전사 기능과 검증 게이트를 침범하지 않도록 하기 위한 작업 문서다.

## 개발 목적

- 반복 사용 중인 절차형 지그재그 파형을 앱의 데이터 흐름을 설명하는 전용 이미지 에셋으로 교체한다.
- `음성 실 → 안전한 청크 → 기록 보관함`이라는 하나의 시각 언어로 온보딩, 녹음 상태, 보관함, 런처 아이콘을 연결한다.
- ImageGen으로 생성한 7종 에셋을 Android 리소스에 등록하고 실제 Compose 화면 및 앱 아이콘에 적용한다.

## 개발 범위

- 온보딩 1 `긴 음성 기록`: 음성 실이 안전 청크로 나뉘어 봉인되는 이미지 1종
- 온보딩 2 `기록 보관함`: 음성 실이 오디오·전사·선택적 요약 카드로 정리되는 이미지 1종
- 녹음 준비: 잔잔한 음성 실과 준비된 청크 슬롯 이미지 1종
- 녹음 진행: 활성 음성 실과 기록 중인 청크 이미지 1종
- 녹음 완료: 확정·봉인된 청크와 완료 표시 이미지 1종
- 보관함 빈 화면: 비어 있는 보관 슬롯과 도착 대기 중인 음성 실 이미지 1종
- 앱 아이콘: 구리색 음성 실과 보관함 슬롯/기록점을 결합한 브랜드 마크 1종
- 생성 이미지의 Android 리소스 등록, Compose 상태 매핑, adaptive/legacy launcher 적용
- `config/asset-manifest.tsv` 출처·크기·SHA-256 갱신

## 문서 기반 제약 사항

- 제품 팔레트 `ArchiveInk #151614`, `ArchivePaper #EEE8DC`, `ArchiveCopper #C07148`, `ArchiveMoss #7E8C78`, `ArchiveFog #A9AAA3`를 유지한다.
- 이미지 안에 문구를 삽입하지 않고 Compose 텍스트와 접근성 설명을 사용한다.
- 전사 원문, OAuth 정보, 녹음 파일 또는 사용자 식별 정보는 이미지·로그·문서에 포함하지 않는다.
- 신규 패키지 에셋은 모두 `asset-manifest.tsv`에 생성 경로와 출처를 기록한다.
- 큰 글자·스크롤·축소 화면에서 핵심 액션을 가리지 않도록 기존 레이아웃 높이와 크롭 경계를 보존한다.
